manifest / the Manifest Network CLI

Heroku-style deploys for Manifest Network boxes. Push a commit, watch it build, see it live.

Install curl -fsSL https://sarsondigital.github.io/aoraki-cli/install.sh | sh

macOS (Apple Silicon & Intel) and Linux x64 · or build from source

What it does

manifest deploys your app to the Manifest Network and keeps you close to it afterwards: stream build output as it happens, tail live pod logs, check what's deployed against your local HEAD, and roll a restart without a rebuild. Every deploy is recorded on the box and reported to the Aoraki console, so your team sees who shipped what, where, and when. Only committed code deploys — there is deliberately no way to push an uncommitted working tree.

Quick start

# 1. Connect to your Aoraki console (opens the tokens page — paste a token)
aoraki login --url https://aoraki.manifest.network/api/v1

# 2. Describe your app once — aoraki.toml at the app root
aoraki link      # sets up the deploy target (idempotent)
aoraki doctor    # preflight the whole chain end-to-end

# 3. Ship
aoraki deploy staging
aoraki logs staging -f

Commands

aoraki loginconnect this machine to an Aoraki console — supports multiple consoles (company, personal) as named remotes
aoraki deploy [env]push and deploy; production environments require typed confirmation
aoraki logs [env] -ffollow application logs from the running pods
aoraki status [env]deployed commit vs local HEAD, pod readiness, drift
aoraki deploysrecent deploy history
aoraki run [env] -- cmdone-off command in a pod with the deployed image
aoraki restart [env]rolling restart without a build
aoraki doctorverify SSH, hooks, docker, kubectl, console token — with fix hints
aoraki whoamiwhich account each stored token belongs to
