aoraki testnet

tester's quickstart

Ship a container to a live HTTPS URL on the Aoraki testnet — play money, real infrastructure.

1 · Create a testnet account

Open testnet.aoraki.cloud, sign in (wallet login), and create an org — that org owns everything you deploy.

Testnet accounts are free: your org's wallet is auto-funded with testnet PWR by the platform treasury. No real money exists here.

2 · Install the CLI

brew install sf-digital-labs/tap/aoraki
# or, without Homebrew:
curl -fsSL https://sf-digital-labs.github.io/aoraki-cli/install.sh | sh

3 · Connect the CLI

In the console, open CLI keys and create a key, then:

aoraki login testnet --url https://testnet.aoraki.cloud/api/v1
# paste the cli_… key when prompted, then verify:
aoraki whoami testnet

This adds a testnet remote alongside any others in ~/.config/aoraki/config.toml — one CLI, many environments, picked per command with --remote.

4 · Deploy something

A known-good demo image, live in about 15 seconds:

aoraki launch --remote testnet \
  --image traefik/whoami:v1.10 --port 8080 \
  --env WHOAMI_PORT_NUMBER=8080

launching 'whoami' → traefik/whoami:v1.10 (org: …, remote: testnet)
deployment dpl_… registered — waiting for the lease…
lease 01a0… active — 28800 µPWR/hr
live: https://web-xxxxxxx.barney11.testnet.manifest0.net/

Your deployment, its lease, and its hourly PWR cost all appear in the console under your org.

5 · Deploy your own image

Build and push anywhere public, then launch it:

docker buildx build --platform linux/amd64 -t ghcr.io/you/yourapp:v1 --push .
aoraki launch --remote testnet --image ghcr.io/you/yourapp:v1 --port 8080
Image contract — the testnet provider rejects anything else:
  • Allowed registries: docker.io, ghcr.io, or the platform registry registry.aoraki.cloud — images must be anonymously pullable (on ghcr, flip the package to Public after the first push; platform-registry push access is provisioned by the Aoraki team)
  • linux/amd64 — build with --platform linux/amd64 on Apple Silicon
  • Runs as non-root — no writing outside /tmp, no privileged setup
  • Listens on a port > 1024 (non-root can't bind 80) — pass it as --port

    • 6 · Custom domains

    aoraki launch --remote testnet --image … --port … --domain yoursite.com

    The domain is claimed on-chain for your lease. Point DNS at the printed FQDN — CNAME yoursite.com → web-….testnet.manifest0.net, DNS only (no proxy) so the certificate can issue. If HTTPS hasn't come up a few minutes after DNS resolves, restart the deployment from the console to retrigger issuance.
